> Generated by `pnpm licenses:report` (tools/checks/supply-chain.mjs). Do not edit by hand.
> The policy is tools/checks/supply-chain-policy.json; `pnpm check` fails on a license it does not
> allow and on a dependency with an install script nobody approved.

Allowed without discussion: MIT, MIT-0, ISC, Apache-2.0, BSD-2-Clause, BSD-3-Clause, 0BSD, BlueOak-1.0.0, CC0-1.0, Unlicense, Zlib, Python-2.0. For an `A OR B` expression one allowed
side is enough; for `A AND B` both must be.

## Exceptions (reviewed)

- `@fontsource-variable/inter`: SIL OFL 1.1 font. The license allows bundling the font in a web app and in commercial products; it only forbids selling the font on its own.
- `caniuse-lite`: CC-BY-4.0 data used by build tools (browserslist). It is not part of the bundle sent to browsers; attribution is kept in docs/LICENSES.md.
- `@img/sharp-*`: Apache-2.0 AND LGPL-3.0-or-later (libvips binaries). An optional dependency of Next's image optimizer, which the static export does not use (images.unoptimized); it is never shipped.
- `lightningcss*`: MPL-2.0, file-level copyleft. A build tool used unmodified by Tailwind; nothing of it is distributed.
